Exportar backup

Gera um arquivo .json com todos os dados do sistema (ingredientes, produtos, vendas, clientes, financeiro etc.) para guardar em local seguro.

Selecione um arquivo .json exportado anteriormente para restaurar todos os dados. Isso substituirá os dados atuais.

Zona de risco

Limpar todos os dados é uma ação irreversível. Recomendamos exportar um backup antes de continuar.
